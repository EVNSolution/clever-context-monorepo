# Root Index

이 문서는 `clever-context-monorepo`의 공식 시작점이다.

## 읽기 순서

1. `docs/root/index.md`에서 전체 구조를 확인한다.
2. `docs/root/doc-governance.md`와 `docs/root/agent-runtime-governance.md`를 읽고 문서 해석 기준과 실행 기준을 맞춘다.
3. `docs/root/pipeline-governance.md`, `docs/root/architecture-principles.md`, `docs/root/security-reliability.md`, `docs/root/design-system-ux-rules.md`를 읽고 공통 규칙을 확인한다.
4. 필요한 경우 `contracts/`를 확인한다.
5. 대상 서비스가 정해지면 `docs/services/`로 내려간다.
6. 빠른 탐색이 필요하면 `docs/wiki/`를 사용하되 정본 판단은 root와 contracts로 되돌아간다.

## 위치 안내

- `docs/root`: 전역 규칙과 공식 시작점
- `docs/services`: 서비스별 상세 문서
- `docs/wiki`: 빠른 탐색 입구
- `contracts`: 전역 계약과 공통 규칙 기준점
